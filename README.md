
# Antarctic Navigation AI

AI/ML-assisted decision support platform for Antarctic vessel route planning.

The prototype combines iceberg trajectory predictions and NOAA sea-ice observations to evaluate candidate navigation routes based on environmental hazard and route distance.

## Features

- Iceberg trajectory prediction integration
- NOAA sea-ice concentration analysis
- Multiple candidate route generation
- Iceberg hazard assessment
- Sea-ice hazard assessment
- Land/water validation
- Route distance and environmental risk scoring
- Recommended route selection
- Interactive Antarctic map
- Manual latitude/longitude input
- Map-based start/destination selection

## Requirements

- Python 3.12+ recommended
- Git
- Internet connection for map tiles
